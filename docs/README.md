# Документация проекта «Сбор данных с сайтов»

Проект — MCP-стенд для сбора данных с сайтов (включая защищённые антиботом).
Пользователи работают через Kilo Code; агент обращается к тулам стенда.

## За 30 секунд

- **Я пользователь** → см. `USER-GUIDE.md` — подключение в Kilo Code.
- **Я администратор** → см. `ADMIN-GUIDE.md` — ключи, мониторинг, обновления.
- **Я ставлю с нуля** → выбери сценарий ниже.

## Как выбрать сценарий установки

| Условие | Сценарий |
|---------|----------|
| Машина небольшая (2 CPU / 4 GiB / 40 ГБ), Firecrawl не нужен | **LITE** → `DEPLOY-NOGIT-LITE.md` (без git) или `DEPLOY-GIT.md` (с git) |
| Нужен Firecrawl (`scrape_markdown`), машина ≥ 4–8 GiB | **FULL** → `DEPLOY-NOGIT-FULL.md` или `DEPLOY-GIT.md` |
| Умеешь и любишь git | `DEPLOY-GIT.md` (легче обновлять) |
| Git ставить нельзя/не хочется | `DEPLOY-NOGIT-*.md` (архив через curl) |

## Состав комплекта

| Файл | Кому | О чём |
|------|------|-------|
| `DEPLOY-NOGIT-LITE.md` | инженер/админ | LITE без git, Ubuntu 24 |
| `DEPLOY-NOGIT-FULL.md` | инженер/админ | FULL (воркеры+Firecrawl) без git |
| `DEPLOY-GIT.md` | инженер/админ | оба варианта с git и обновление |
| `ADMIN-GUIDE.md` | администратор | ключи, статус, диагностика, безопасность |
| `USER-GUIDE.md` | пользователь/поддержка | подключение в Kilo Code |
| `MONITORING.md` | администратор | опциональный мониторинг (Prometheus) |
| `SOFTWARE-STACK.md` | информационно | стек ПО, порты, структура репозитория |

## Термины

- **Стенд** — сервер с воркерами (и, в FULL, Firecrawl), к которому обращаются тулы.
- **Воркер** — контейнер с антидетект-браузером (`camou` :3100, `cloak` :3101).
- **Мост (bridge)** — `firecrawl_node_bridge.js` на машине пользователя; передаёт
  вызовы агента на стенд.
- **Тул** — функция MCP: `scrape_url`, `scrape_cloak`, `scrape_wb`, `scrape_ozon`,
  `scrape_markdown`.
- **Токен** — персональный ключ доступа к воркерам.

## Безопасность (кратко)

- `tokens.txt` и `.env` — на сервере, chmod 600, НЕ в git.
- Токены персональные; отзыв — `manage-keys.sh revoke <имя>`.
- Снаружи открывай только нужные порты: 3002 (FULL), 3100, 3101.
- Секреты из прошлых версий в репозитории не найдены (проверено).
