# Инструкция пользователя

Эта страница — что сделать **один раз**, чтобы в Kilo Code агент умел собирать
данные с сайтов (в том числе защищённых от ботов). После настройки ты просто
просишь агента, а он сам использует нужные тулы.

---

## 1. Что нужно приготовить

- Установленный **Kilo Code**.
- **Node.js 18+** (проверь):
  ```bash
  node --version     # ож. v18.x или выше
  ```
  Если нет — установи LTS с [nodejs.org](https://nodejs.org).
- **Персональный токен** — выдаёт администратор (`manage-keys.sh gen <имя>`).
- Адрес(а) стенда — обычно `http://<IP>:3100` и `http://<IP>:3101`.

## 2. Положить файл моста

Возьми `mcp/firecrawl_node_bridge.js` (из репозитория, у администратора или
коллеги) и положи в удобное место, например:
- Windows: `C:\Users\<Имя>\mcp\firecrawl_node_bridge.js`
- macOS/Linux: `~/mcp/firecrawl_node_bridge.js`

## 3. Настроить конфиг Kilo

Открой `~/.config/kilo/kilo.jsonc` (Windows: `%USERPROFILE%\.config\kilo\kilo.jsonc`).
Добавь секцию `mcp` — не удаляя то, что уже есть:

```jsonc
{
  "mcp": {
    "firecrawl-stack": {
      "type": "local",
      "command": ["node", "/ПОЛНЫЙ/ПУТЬ/firecrawl_node_bridge.js"],
      "environment": {
        "WORKER_URL": "http://<IP>:3100/scrape",
        "CLOAK_WORKER_URL": "http://<IP>:3101/scrape",
        "AUTH_TOKEN": "<твой-персональный-токен>"
      },
      "enabled": true
    }
  }
}
```

Важно:
- В `command` — **абсолютный путь** к мосту (без `~`).
- Windows: обратные слеши экранируются `\\`:
  `"C:\\Users\\Иван\\mcp\\firecrawl_node_bridge.js"`.
- `FIRECRAWL_URL` добавляй, только если на стенде есть Firecrawl (FULL-версия).

## 4. Установить скилл (обязательно)

Скилл учит агента: если сайт показал капчу/«Проверяем браузер» — сам уходить на стенд.
Скопируй папку скилла в свой проект:
```bash
mkdir -p <проект>/.kilo/skill
cp -r <репо>/skill/firecrawl-stack <проект>/.kilo/skill/
```
(цель: `<проект>/.kilo/skill/firecrawl-stack/SKILL.md`)

## 5. Перезапуск и проверка

1. **Полностью закрой и открой VS Code** (не только Reload).
2. Открой `/mcps` → кнопка `firecrawl-stack` статус **Connected**.
3. В диалоге должны появиться тулы: `scrape_url`, `scrape_cloak`, `scrape_wb`,
   `scrape_ozon` (+ `scrape_markdown`, если FULL).

Быстрая самопроверка: напиши агенту **«собери топ-3 принтера на Wildberries»** —
вернёт список с ценами через `scrape_wb`.

## 6. Как пользоваться

| Что нужно | Каким тулом это делает агент |
|-----------|------------------------------|
| Обычный сайт (новости, статьи) | `scrape_url` (или `scrape_markdown` в FULL) |
| Wildberries, товары с ценами | `scrape_wb` |
| Ozon | `scrape_ozon` (названия/ссылки; цен Ozon не отдаёт) |
| Сайт с «Проверяем браузер»/Turnstile/403 | `scrape_cloak` |

Не думай о тулах руками — агент (по скиллу) выберет сам. Можно явно попросить:
«используй scrape_cloak» — всё равно он решает, какая тула надёжнее.

## 7. Если что-то не работает

| Симптом | Решение |
|---------|---------|
| `401` при запросах | неверный/не выдан токен → уточни у администратора |
| `/mcps` сервера нет | проверь пути (абсолютный путь к мосту), перезапусти VS Code |
| Ozon отдаёт `ip-blocked` | без жилого прокси это норма; повтори позже |
| мост «устарел» (новые тулы не видны) | обнови `firecrawl_node_bridge.js` из репозитория |
| агент жалуется «не собрал» | попроси «используй scrape_wb / scrape_cloak» явно |

## 8. Безопасность

- Токен персональный — не передавай его никому.
- Не запускай много параллельных запросов: воркер — один браузер, лучше держать
  интервал в несколько секунд.
