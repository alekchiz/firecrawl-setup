# Настройка у коллег: доступ к сбору данных с сайтов через Kilo Code

Короткая памятка. Цель — чтобы в локальном Kilo Code (любая модель, включая
DeepSeek) агент умел собирать данные с сайтов, а при антиботе автоматически
уходил на наш стенд.

## Быстрая установка (одна команда)

Склонируй репозиторий и запусти установщик:
```bash
git clone git@github.com:alekchiz/firecrawl-setup.git
cd firecrawl-setup
```
Установка — Node.js 18+ (нужен и так), одна команда, работает на macOS/Linux/Windows:
```bash
node install-kilo.js
```
В PowerShell/CMD: `node install-kilo.js` (пиши без `./`). Без SSH-ключа —
`git clone https://github.com/alekchiz/firecrawl-setup.git`. Если хочется нативный
bash на macOS/Linux — `./install-kilo.sh`, на Windows — `.\install-kilo.ps1`
(но там может мешать политика выполнения PowerShell).

Установщик сам: проверит Node.js 18+, положит мост в `~/mcp/`, поднимет скилл
на проект и впишет секцию `mcp` в `~/.config/kilo/kilo.jsonc`, не трогая
остальное. Токен возьмёт из строки `AUTH_TOKEN=...` в `.env` (файл в gitignore,
не коммитится) или спросит. Адреса меняются переменными `WORKER_IP` и
`FIRECRAWL_URL`. После запуска — перезапусти VS Code.

Ниже — та же настройка вручную.

## Что понадобится

1. Установленный Kilo Code.
2. `python3` на машине (на macOS обычно уже есть). Проверка: `python3 --version`.
3. Доступ к стенду по сети:
   - Воркер (антидетект): `http://194.242.122.178:3100/scrape`
   - Firecrawl (обычные сайты): `http://109.94.1.210:3002`
   Эти адреса публичные, дополнительных VPN/туннелей не нужно.

## Шаг 1. Файл скрипта

Скрипт-мост лежит в репозитории: `mcp/firecrawl_mcp.py`.
Скопировать его в любое место, например:
```bash
mkdir -p ~/mcp
cp mcp/firecrawl_mcp.py ~/mcp/firecrawl_mcp.py
```

## Шаг 2. Конфиг MCP

В свой конфиг Kilo (`~/.config/kilo/kilo.jsonc` или проектный `kilo.jsonc`)
добавить блок `mcp`. Путь в `command` — **абсолютный**, указывать на скопированный файл.

```jsonc
{
  "mcp": {
    "firecrawl-stack": {
      "type": "local",
      "command": ["python3", "/ПОЛНЫЙ/ПУТЬ/firecrawl_mcp.py"],
      "environment": {
        "WORKER_URL": "http://194.242.122.178:3100/scrape",
        "FIRECRAWL_URL": "http://109.94.1.210:3002",
        "AUTH_TOKEN": "вставить-выданный-токен"
      },
      "enabled": true
    }
  }
}
```

`AUTH_TOKEN` выдаёт администратор. Без него воркер отвечает `401`.

## Шаг 3. Скилл (чтобы агент сам уходил на стенд при антиботе)

Скопировать папку скилла в свой проект:
```bash
mkdir -p <ваш_проект>/.kilo/skill
cp -r skill/firecrawl-stack <ваш_проект>/.kilo/skill/
# или целевая структура:
mkdir -p <ваш_проект>/.kilo/skill/firecrawl-stack
cp skill/firecrawl-stack/SKILL.md <ваш_проект>/.kilo/skill/firecrawl-stack/
```

Если работаете прямо в этом репозитории — скилл уже лежит в `.kilo/skill/`, ничего копировать не нужно.

## Шаг 4. Перезагрузка и проверка

1. Перезапустить Kilo или открыть `/mcps` — сервер `firecrawl-stack` должен быть активным.
2. Проверить, что тулы появились: `scrape_url`, `scrape_markdown`.
3. Тест: попросить агента «собери данные с сайта X». Агент по скиллу
   `firecrawl-stack` сам обратится к `scrape_markdown` (обычный сайт) или
   `scrape_url` (маркетплейс/защищённый сайт).

## Поведение скилла (что делает агент)

- `scrape_markdown(url)` — Firecrawl, обычные сайты, быстрый markdown.
- `scrape_url(url)` — антидетект-воркер (Camoufox), маркетплейсы и сайты с
  «Проверяем браузер»/капчей внутри; возвращает `status`, `title`, текст.
- Если сайт вернул `captcha` / `ip-blocked` — агент сообщает об этом и предлагает повторить позже.

## Ограничения и безопасность

- **Токен общий.** Не распространяй его дальше своей команды; при утечке он
  меняется на сервере, и старый перестаёт работать.
- **Воркер — один браузер, запросы последовательные.** Не гоняй пачками
  одновременно — держи интервал несколько секунд, иначе сайты начнут капчи.
- Один запрос занимает ~5–30 сек — не дублируй его.
- Скрейпинг идёт с IP стенда: не собирай персональные/закрытые данные без прав.

## Тулы и порты

У MCP-сервера `firecrawl-stack` четыре тула:
- `scrape_url` — Camoufox-воркер (`194.242.122.178:3100`).
- `scrape_cloak` — CloakBrowser (`194.242.122.178:3101`) — для Turnstile/«403»
  (например DNS-шоп).
- `scrape_markdown` — Firecrawl (`109.94.1.210:3002`).
- `scrape_wb` — товары Wildberries через фирменный API WB.

Воркеры живут на облачном сервере `194.242.122.178` (публичные порты `3100`,
`3101` уже открыты, NAT/туннелей не нужно). Firecrawl с `3002` остался на
домашнем сервере `109.94.1.210` — туда проброшены порты роутера.

## Что происходит при запросе (по шагам)

1. Коллега пишет агенту, например: «топ-3 принтера с Wildberries».
2. Агент по скиллу `firecrawl-stack` выбирает тул:
   - для обычных сайтов — `scrape_markdown`;
   - для маркетплейсов/защищённых — `scrape_url` (Camoufox) или `scrape_cloak`
     (CloakBrowser, для Turnstile/«403»);
   - для товаров Wildberries — `scrape_wb`.
3. Мост `firecrawl_node_bridge.js` отправляет запрос на нужный воркер стенда.
4. Воркер открывает браузер, переходит на URL, ждёт загрузку/гидратацию.
   Если появилась капча-слайдер (Ozon) — солвер делает несколько попыток драга.
   При 429 (WB API) `scrape_wb` сам ждёт и повторяет (до 6 раз с нарастающей
   паузой).
5. Воркер определяет статус: `ok` (контент получен), `captcha`, `ip-blocked`
   или `error` — и возвращает текст/HTML. Агент отдаёт результат пользователю,
   а при `captcha`/`ip-blocked` предлагает повторить позже.

## Проверено без прокси

| Сайт | camou (:3100) | cloak (:3101) |
|------|---------------|---------------|
| WB / Авито / М.Видео / Ситилинк / hh / Дром / Mail / Райффайзен | ✅ | ✅ |
| DNS-шоп | ⚠️ «HTTP 403» | ✅ (CloakBrowser) |
| Lamoda | ⚠️ пусто | ⚠️ пусто |
| Ozon / Авито | ✅ | ✅ |
| Мегамаркет | ❌ «Упс…» | ❌ «Упс…» |

IP `194.242.122.178` чистый: Ozon и Авито открываются напрямую без прокси.
Прокси (`PROXY_URL`) нужен только если снова столкнёшься с `ip-blocked`.

## Про капчу: «сам разберётся?»

Да. В скилле заложено жёсткое правило: капча, «Проверяем браузер», Cloudflare,
403 или пустой ответ со стороны `webfetch` — это НЕ финал. Агент обязан
переключиться на стенд (`scrape_url` / `scrape_cloak` / `scrape_markdown`) и
только потом докладывать. Если всё равно не получилось — воркер честно вернёт
`captcha` / `ip-blocked`, и агент предложит повторить позже. Важно, чтобы у
коллеги был подключён MCP и лежал скилл (шаги выше).
