# Документация проекта

Комплект инструкций «от системного инженера» — полный, пошаговый, для любого уровня.

| Раздел | Файл | О ком |
|--------|------|-------|
| Развёртывание LITE без git | `DEPLOY-NOGIT-LITE.md` | системный инженер / админ |
| Развёртывание FULL без git | `DEPLOY-NOGIT-FULL.md` | системный инженер / админ |
| Развёртывание через git | `DEPLOY-GIT.md` | системный инженер / админ |
| Стек ПО и утилит | `SOFTWARE-STACK.md` | информационно |
| Инструкция администратора | `ADMIN-GUIDE.md` | администратор |
| Инструкция пользователя | `USER-GUIDE.md` | пользователь / техподдержка |
| Мониторинг (опц.) | `MONITORING.md` | администратор |

Схема выбора:
1. Пользователь — только `USER-GUIDE.md`.
2. Администратор — `ADMIN-GUIDE.md` (+ docs с развертыванием при необходимости).
3. Первичная установка — выбери сценарий: LITE (лёгкая машина) или FULL (>Firecrawl).

Связанные материалы: `FOR-COLLEAGUES.md` (кратко для коллег),
`PORTAL-GUIDE.md` (пошаговая для портала), `LITE-STAND.md`,
`LITE-INSTALL-UBUNTU24.md` (установка Ubuntu 24 без git — конспект `DEPLOY-NOGIT-LITE`).
