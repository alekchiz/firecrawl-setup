# Инструкция пользователя: подключение в Kilo Code

Что нужно: установленный **Kilo Code**, **Node.js 18+** и **выданный администратором
токен**. Установка — один раз; далее работаете обычными запросами к агенту.

---

## 1. Подготовка

Проверь Node:
```bash
node --version   # ож. v18+
```
Если нет — установи LTS с nodejs.org (или brew/nvm).

Получи у администратора:
- токен доступа (`AUTH_TOKEN`);
- адрес(а) стенда (обычно `http://<IP>:3100` и `http://<IP>:3101`).

## 2. Файл моста

Скачай `mcp/firecrawl_node_bridge.js` из репозитория и положи в удобную папку,
например `C:\Users\<Имя>\mcp\firecrawl_node_bridge.js` (Windows) или `~/mcp/` (macOS/Linux).
Без git файл можно взять с GitHub (raw) или попросить у администратора/коллеги.

Проверяют наличие: файл существует, `node` находит `firecrawl_node_bridge.js`.

## 3. Конфиг Kilo

Открой `~/.config/kilo/kilo.jsonc` (Windows: `%USERPROFILE%\.config\kilo\kilo.jsonc`;
можно и проектный `kilo.jsonc`). Добавь секцию `mcp` (не ломая существующие ключи):

```jsonc
{
  "mcp": {
    "firecrawl-stack": {
      "type": "local",
      "command": ["node", "/ПОЛНЫЙ/ПУТЬ/firecrawl_node_bridge.js"],
      "environment": {
        "WORKER_URL": "http://<IP-стенда>:3100/scrape",
        "CLOAK_WORKER_URL": "http://<IP-стенда>:3101/scrape",
        "AUTH_TOKEN": "<твой-персональный-токен>"
      },
      "enabled": true
    }
  }
}
```

Важно:
- `command` — **абсолютный путь**; без `~`.
- Windows: обратные слеши экранируются `\\` (например `C:\\Users\\Иван\\mcp\\...`).
- `FIRECRAWL_URL` добавляй, **только если** развёрнута полная версия.

## 4. Скилл (обязательно)

Скопируй папку скилла в проект:
```bash
# цель: <проект>/.kilo/skill/firecrawl-stack/SKILL.md
mkdir -p <проект>/.kilo/skill
cp -r <репо>/skill/firecrawl-stack <проект>/.kilo/skill/
```
Скилл заставляет агента при капче/«Проверяем браузер» сам уходить на стенд.

## 5. Перезапуск и проверка

1. **Полностью перезапусти VS Code** (не Reload).
2. Открой `/mcps` → `firecrawl-stack: Connected`.
3. В диалоге у агента должны появиться тулы:
   `scrape_url`, `scrape_cloak`, `scrape_wb`, `scrape_ozon`
   (+ `scrape_markdown`, если полная версия).

Быстрая проверка: напиши агенту
**«собери топ-3 принтера на Wildberries»** — он вызовет `scrape_wb` и вернёт цены.

## 6. Как пользоваться

| Запрос | Тула (агент выберет сам по скиллу) |
|--------|-------------------------------------|
| обычный сайт (новости/статьи) | `scrape_url` |
| маркетплейсы (WB/Ozon…) | `scrape_wb` / `scrape_ozon` |
| сайт с Turnstile/«403» | `scrape_cloak` |
| полный Firecrawl-стек | `scrape_markdown` |

## 7. Если что-то не работает

- `401` — неверный/не выдан токен (уточни у администратора).
- `ip-blocked` на Ozon — без жилого прокси норма; повтори позже.
- `/mcps` не виден сервер — проверь пути/путь к `node` и перезапусти VS Code.
- Ошибка моста — файл моста устарел: обнови из репозитория.

## 8. Безопасность

- Токен персональный — не передавай третьим лицам.
- Не запускай пачками параллельных запросов: воркер — один браузер,
  лучше интервал несколько секунд.
